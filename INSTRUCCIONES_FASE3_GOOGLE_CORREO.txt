UNIMARKET - FASE 3

1) Ejecuta migracion_fase3_unimarket.sql en phpMyAdmin sobre la base unimarket.

2) Google Login:
- Abre config/google_auth.php.
- Pega tu Client ID en client_id.
- Pega tu Client Secret en client_secret.
- En Google Cloud, usa este Redirect URI:
  http://localhost/unimarket_app/controlador/GoogleAuthController.php

3) Correo recuperación contraseña:
- Abre config/mail_config.php.
- En modo local deja enabled => false. Se mostrará un enlace de prueba en pantalla.
- Para correo real cambia enabled => true y configura SMTP.
- Para Gmail usa contraseña de aplicación.

4) Después de copiar archivos:
- Reinicia Apache si cambiaste php.ini o cURL.
- Abre la web y haz Ctrl + F5.
